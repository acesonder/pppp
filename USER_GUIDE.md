## Getting Started

### Creating Your Account

1. **Navigate to the homepage**
   - Visit the PPPP website
   - Click "Get Started" or "Register"

2. **Fill in registration form**
   - Full Name: Your real name
   - Username: Choose a unique username
   - Email: Valid email address
   - Password: At least 6 characters

3. **Welcome Tour**
   - After registration, you'll see a welcome tour
   - This introduces main features
   - Click "Get Started" to proceed to dashboard

### Logging In

1. Click "Login" button
2. Enter username/email and password
3. Check "Remember Me" for persistent login
4. Click "Login"

### Forgot Password?

1. Click "Forgot Password?" on login page
2. Enter your email address
3. Check email for reset link
4. Follow link to set new password

## Dashboard Overview

### Understanding Your Dashboard

The dashboard is your command center. It shows:

**Quick Stats** (Top Row)
- 📊 Active Tasks count
- 📅 Upcoming Events count
- 📧 Unread Messages count
- 📈 Productivity percentage

**Widgets** (Main Area)
- **Tasks Widget**: Your recent tasks
- **Calendar Widget**: Upcoming events
- **Weather Widget**: Current weather
- **Inbox Widget**: Message notifications

### Customizing Widgets

1. Go to **Settings** (gear icon in navbar)
2. Scroll to "Dashboard Widgets"
3. Toggle widgets on/off
4. Click "Save Widget Settings"

### Navigation Bar

**Left Side:**
- 🏠 Dashboard: Go to main dashboard
- ✅ Tasks: Manage your tasks
- 📅 Calendar: View calendar and events
- 🛡️ Admin: Admin panel (admins only)

**Right Side:**
- 🔔 Notifications: See activity updates
- 📧 Messages: Quick message preview
- 👤 Profile: Access profile menu

## Task Management

### Creating a Task

1. **From Dashboard:**
   - Click "+ New Task" in Tasks widget
   
2. **From Tasks Page:**
   - Click Tasks in navbar
   - Click "+ New Task" button

3. **Fill in Details:**
   - **Title**: What needs to be done
   - **Description**: Detailed information
   - **Priority**: Low, Medium, High, or Urgent
   - **Due Date**: When it's due (optional)

4. Click "Create Task"

### Managing Tasks

**View Tasks:**
- All tasks are listed on Tasks page
- Color-coded by priority (left border)
- Shows status, priority, and due date

**Filter Tasks:**
- Click filter buttons:
  - All Tasks
  - Pending
  - In Progress
  - Completed

**Edit Task:**
1. Click "Edit" button on task card
2. Modify details
3. Update status if needed
4. Click "Update Task"

**Delete Task:**
1. Click "Delete" button
2. Confirm deletion
3. Task is permanently removed

### Task Priorities

- **🔴 Urgent**: Critical, needs immediate attention
- **🟠 High**: Important, should be done soon
- **🟡 Medium**: Regular priority
- **⚪ Low**: Can wait, not urgent

### Task Statuses

- **⏳ Pending**: Not started yet
- **🔄 In Progress**: Currently working on it
- **✅ Completed**: Finished
- **❌ Cancelled**: No longer needed

## Calendar & Events

### Viewing Calendar

1. Click "Calendar" in navbar
2. View current month
3. Events appear on their dates
4. Click event to view details

### Navigating Months

- **◀ Previous**: Go to previous month
- **▶ Next**: Go to next month
- Current month/year is displayed

### Creating an Event

1. Click "+ New Event"
2. Fill in details:
   - **Title**: Event name
   - **Description**: What it's about
   - **Date**: When it happens
   - **Time**: Specific time (optional)
   - **Location**: Where it happens (optional)
3. Click "Create Event"

### Managing Events

**Edit Event:**
1. Click event in calendar or list
2. Modify details
3. Click "Update Event"

**Delete Event:**
1. Click delete button (🗑️)
2. Confirm deletion

**Event List:**
- Below calendar shows all events this month
- Organized by date
- Shows full details

## Messenger

### Starting a Conversation

1. Click "Messenger" or envelope icon
2. Select user from conversation list
3. Start typing in message box
4. Press Enter or click send (✈️)

### Understanding the Interface

**Left Panel - Conversations:**
- List of all conversations
- Shows last message preview
- Unread count badge
- Online status indicator (green dot)

**Right Panel - Chat:**
- Selected conversation
- Message history
- Input box at bottom

### Sending Messages

1. Type in message box
2. Press Enter or click send button
3. Message appears immediately
4. Messages are saved in database

### Message Features

- **Search**: Find conversations quickly
- **Unread Indicators**: Blue badges show unread count
- **Online Status**: Green dot = user is active
- **Timestamps**: See when messages were sent
